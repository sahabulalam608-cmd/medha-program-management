📋 Sheet playbook

The MPM site reads from and writes to the same Google Sheet you already use. So even if the site is offline, you can still do everything from the sheet directly.

Open the Medha sheet ↗

Tabs in the sheet

  • Members NCM-P1 — everyone in PART-1
  • Members NCM-P2 — everyone in PART-2
  • EmailLog — every mail the site/Apps Script sent
  • Settings — Form on/off, deadlines, closed messages
  • _ProgramMail_Help — auto-created instructions

Common tasks without the site

  • Mark someone as Sent: Status cell → pick Sent → type timestamp in SentAt (e.g. 21-10-2026 13:50)
  • Skip a recipient: Status → Skip (the site never sends to them)
  • Add new member: next empty row, fill SL/Member ID/Name/Email. They'll appear on the site within 30s.
  • Bulk update: select multiple rows → Edit Status cell once → picks apply to all
  • Open/close Application form: Settings tab → FORM_OPEN → YES or NO
  • Set form deadline: Settings → FORM_DEADLINE → 21-10-2026 23:59
  • Edit closed-message: Settings → CLOSED_MSG_BN / CLOSED_MSG_EN
  • See who got mail: EmailLog tab, sort by Timestamp desc

Reset dropdowns after manual edits

If Status cells stop showing the dropdown (e.g. you paste rows from elsewhere), run setupProgramSheets in the Apps Script editor — it re-applies validation and headers. Re-run any time, it's idempotent.

Two-way sync guarantee

Every change the site makes (mails sent, status updates, settings toggles) writes directly to the sheet via Apps Script. If you change something in the sheet, refresh the site (↻ button on Members page) — it pulls fresh within seconds.
